Manga-trans v2 — 실제 레이어 구조

기반 파일: /Users/bagjimin/dev/Manga-trans/ (프로젝트 폴더 기준)

전체 아키텍처

입력: 이미지 → Step 1. 검출 → Step 2. 인페인팅 → Step 3. OCR → Step 4. 번역 → Step 5. 식자 → 출력: _ko.png
진입점은 python3 main.py(단일) 또는 python3 run_batch.py(다중).
중간파일은 tempfile.TemporaryDirectory에 격리하고, 출력 폴더에는 최종 _ko.png만 복사.

계층별 파일과 역할

파일 계층 하는 일 비고
main.py 오케스트레이터 process_page()가 5단계 실행.
각 레이어 클라이언트를 모듈 캐시로 유지(_DETECTOR_CACHE/_OCR_CLIENT_CACHE/_TRANSLATOR_CACHE).
예외/부분실패 허용, tempdir 격리, QA 호출. 		core
run_batch.py 배치 러너 glob → 정렬 → process_page() 반복.
--resume, --skip-existing, ETA, 페이지 컨텍스트 continuity. 		배치/재시작
config.yaml 설정 단일 설정 파일. comfyui/models/yolo/ocr/translation/inpainting/output/qa 섹션.
모델 경로, provider, threshold, 폰트 기본값, fallback 스위치 포함.
예: output.base_dir, ocr.model, translation.model, comfyui.base_url. 		단일 진실원
detection/yolo_detector.py 검출 bubble_detector → 말풍선 bbox.
text_segmenter → 전체페이지 text mask + 텍스트 bbox.
출력: bubbles/texts/text_mask. 		YOLO 직접 호출
ocr/vlm_ocr.py OCR 말풍선 crop → VLM OCR (4병렬).
CacheManager(hash), fallback 모델, auth fail-fast, [NO TEXT] 정규화. 		가장 느린 단계
translation/translator.py 번역 배치 번역, system-prompt context 격리, comma JSON wrapping, dedup, strict retry.
일본어 잔존/짧은번역 등 invalid 필터링. 		OpenRouter free
comfy_client.py 인페인팅 flat_fill(흰 말풍선, PIL, ~0.3s) 우선.
잔여 mask 있으면 LaMa(ComfyUI REST 8000번).
실패/미가용 시 OpenCV fallback. 		ComfyUI 필요
scripts/render_text.py 식자 PyQt5 QPainter 기반 렌더링.
iterative binary search 폰트 사이즈, WordWrap.
세로 말풍선 vertical=True 지원. 		QPainter 직접
cache_manager.py 인프라 OCR/번역 결과 MD5 해시 캐시.
version prefix(ocr_v4/trans_v6)로 코드 변경시 자동 무효화. 		공유
qa_module.py 검증 결과물 warn/bad threshold 검증, 자동 보고서 생성. 기본 비활성화(qa.enabled: false). 선택
web_gui.py 컨트롤러 로컬 HTTP 서버. single/batch 실행, 결과 목록 조회, 설정값 확인.
표준 라이브러리만 사용. 		옵션
tests/ 검증 test_pipeline_improvements.py
test_comfy_client.py
test_web_gui.py 		pytest

데이터 흐름

input.jpg → run_detection() → DetectionResult{ bubbles, texts, text_mask, width, height }
run_inpainting() → cleaned.png
run_ocr() → [{id, text, bbox}, …]
run_translation() → [{id, original, translation}, …]
run_typesetting() → *_ko.png
중요한점: _ko.png 외 중간 산출물은 출력 폴더에 쓰지 않음. tempfile.TemporaryDirectory에서 자동 정리.
다만 config.yaml의 debug_overlay=true 일 경우 임시 디버그 오버레이가 출력 폴더에 저장될 수 있음.

분기/우선순위

인페인팅 분기

번역 모델 분기

fallback_model ← 재시도/할당량 소진/502시
